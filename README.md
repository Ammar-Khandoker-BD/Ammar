# Growthworks International

Responsive single-page business website for Growthworks International.

## Sections
- Home, company introduction and contact calls to action
- 15 service descriptions with filtering, search and detail modals
- Portfolio concept previews
- About, mission, vision and core values
- Humanity First and the stated 10% donation commitment
- Careers / talent-pool email draft
- WhatsApp project enquiry form

## Publish
This repository includes a GitHub Actions workflow at `.github/workflows/pages.yml`. It configures GitHub Pages and deploys the website whenever changes are pushed to `main`.

Expected URL: https://ammar-khandoker-bd.github.io/Ammar/

## Before promoting publicly
- Add the official business address and social profile URLs when available.
- Replace portfolio concept previews with verified work and client-approved case studies.
- Publish donation reports only when documented records are available.
- Contact and career forms open WhatsApp or an email draft; they do not store submissions on a server.
- Outcomes such as search ranking, verification approval, sales or account restoration are not guaranteed.

The brand mark is recreated as a lightweight inline SVG based on the supplied reference image.
